## Definition of Ready

Uma história entra em desenvolvimento quando possui objetivo, critérios de aceite, requisitos vinculados, dependências, regras de negócio e riscos identificados.

## Definition of Done

Uma história é concluída quando possui código revisado, testes aprovados, critérios de aceite atendidos, requisitos de segurança aplicáveis homologados, documentação atualizada e nenhuma falha crítica aberta.
