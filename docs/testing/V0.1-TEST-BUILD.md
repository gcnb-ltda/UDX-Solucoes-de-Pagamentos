# UDX Pay v0.1.0-test

Primeiro pacote instalável para homologação visual e funcional inicial.

## Artefatos

- `udx-pay-web-v0.1.0-test`: export estático do frontend Next.js.
- `udx-pay-android-v0.1.0-test`: APK Android debug encapsulado com Capacitor.

## Escopo

A build apresenta a interface inicial UDX Pay e serve para validar navegação, identidade visual, responsividade, instalação Android e integração futura com a API de testes.

A versão não habilita movimentação financeira real. O backend mantém provider real desabilitado até contratação/configuração/homologação externa.

## Android

O APK é uma build `debug`, adequada a instalação manual em aparelho de teste. Não é uma build assinada para Google Play e não deve ser distribuída como produção.

## Web

O bundle em `out/` é totalmente estático e pode ser servido por Nginx, Apache, S3/CloudFront, GitHub Pages ou servidor HTTP equivalente. A URL da API é incorporada no build por `NEXT_PUBLIC_API_URL`.
