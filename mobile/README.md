# UDX Pay Mobile

Aplicativo móvel da UDX Soluções de Pagamentos.

## Escopo inicial

- Login/MFA
- Dashboard
- Receber via Pix
- Link de pagamento
- Histórico de transações
- Saldo e recebíveis
- Notificações

## Stack proposta

React Native + Expo, consumindo a API UDX `/api/v1`.

A implementação mobile deve preservar biometria, armazenamento seguro de tokens e controles contra dispositivos comprometidos conforme a evolução do projeto.
